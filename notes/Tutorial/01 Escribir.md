# Escribir

Cada párrafo, título, lista o imagen es un **bloque**. Escribes en un bloque y pulsas **Enter** para crear el siguiente.

## Formato

- **Negrita**: selecciona el texto y pulsa `Ctrl+B`, o escribe `**así**`.
- *Cursiva*: `Ctrl+I`, o `*así*`.
- Código en línea: `` `así` ``.

## Títulos y listas

Escribe `#` seguido de espacio para un título grande, `##` para el mediano y `###` para el pequeño. `-` crea una lista, `1.` una numerada y `[]` una tarea.

- [ ] Esta tarea se marca con la casilla. Pulsa `Ctrl+Enter` sobre una tarea para cambiar su estado.
- [x] Esta ya está hecha.

> Una cita se escribe con `>` al principio.

## Mover bloques

Pasa el ratón a la izquierda de un bloque: aparece un asa `⋮⋮`. Arrástrala para cambiar el bloque de sitio, o haz clic para ver sus opciones.

## Navegar con el teclado

- `↑` y `↓` saltan de un bloque a otro.
