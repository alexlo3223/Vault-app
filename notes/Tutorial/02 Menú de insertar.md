# Menú de insertar

Escribe `/` en un bloque, o haz clic derecho sobre él. Aparece un menú con todo lo que puedes insertar, agrupado por secciones:

- **Basic blocks**: texto, títulos, listas, tareas, citas, callouts, código, divisores, enlace a página, tabla simple y botón para crear notas.
- **Database**: tabla, tablero, galería, lista, número y donut (ver [[06 Bases de datos]]).
- **Media**: imagen, vídeo, audio, archivo, marcador web e incrustación.
- **Layout**: columnas (ver [[04 Columnas y medios]]).
- **Page**: enlaces a las subpáginas de esta página.

Escribe parte del nombre para filtrar: `/tabla`, `/galería` o `/callout`.

## Callouts

Un callout es un aviso con color. Se escribe así:

~~~markdown
> [!tip] Título del aviso
> Texto del aviso.
~~~

Tipos: `note`, `info`, `tip`, `success`, `warning` y `danger`. Cada uno tiene su color.

> [!tip] Ejemplo
> Este bloque es un callout de tipo `tip`. Insértalo desde el menú o escribe la sintaxis de arriba.

## Botón para crear notas

El bloque **Button: new note** crea un botón. Al pulsarlo se crea una nota nueva en la carpeta que indiques (vacía significa la raíz). Es útil para plantillas de diarios o de reuniones.
