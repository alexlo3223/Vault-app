## Bienvenido

Vault guarda tus notas como archivos Markdown normales, y también las abre Obsidian. Estas páginas explican cada función con ejemplos que puedes tocar.

> [!tip] Cómo usar el tutorial
> Sigue la lista de la izquierda en orden, o salta a lo que te interese. Para ver una página terminada, abre [[Ejemplo Biblioteca]]: reproduce un panel con banner, columnas, botones, galería y gráfico.

## Ejemplo vivo

Una base de datos con sus vistas. Cambia de pestaña, edita una celda o añade una fila:

```database
page: Tutorial/Libros
use: Leyendo, Leídos, Pendientes, Tabla
```

## Atajos

- `Ctrl+K` busca en todas tus notas
- `/` abre el menú de insertar
- `Ctrl+B` / `Ctrl+I` negrita y cursiva
- `Enter` abre y guarda una celda
