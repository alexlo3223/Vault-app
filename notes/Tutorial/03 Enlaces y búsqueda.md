# Enlaces y búsqueda

## Enlazar notas

Escribe `[[` y el nombre de otra nota: Vault te ofrece las que coinciden. Así se crea un enlace como [[Tutorial]].

Si enlazas una nota que aún no existe y pulsas el enlace, Vault la crea vacía.

## Etiquetas

Escribe `#` seguido de una palabra para etiquetarla, por ejemplo #tutorial o #lectura. Las etiquetas aparecen en la búsqueda y en el resumen.

## Buscar: Ctrl+K

Pulsa `Ctrl+K` para abrir la búsqueda. Puedes combinar filtros:

- `tag:lectura` notas con esa etiqueta.
- `path:Tutorial` notas dentro de una carpeta.
- `"frase exacta"` busca la frase tal cual.
- `-palabra` excluye las notas que la contienen.

Usa `↑` y `↓` para moverte por los resultados y `Enter` para abrir uno.

## Enlaces externos

Un enlace web (`https://…`) se abre en tu navegador. Para incrustar una página o un vídeo, usa el bloque *Embed or video link* (ver [[04 Columnas y medios]]).
